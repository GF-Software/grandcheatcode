compra de teste

1. Baixe o seu pacote

O arquivo sai com o seu nome e a sua licença em cada página.

No celular o arquivo vai para Arquivos ou Downloads. A instalação é feita no computador.

2. Instale copiando e colando

Você não precisa descompactar nada. Escolha onde vai usar:

  1. Baixe o pacote no passo 1. Ele vai para a pasta Downloads.
  2. Abra o aplicativo do Claude no computador, aba Code. Embaixo da caixa de mensagem, clique na pasta e escolha uma pasta nova e vazia (por exemplo, crie Documentos/grand-cheat-code). Deixe o modo de permissão em Manual.
    Prefere o terminal? Rode mkdir -p ~/grand-cheat-code && cd ~/grand-cheat-code && claude e confirme que confia na pasta.
  3. Copie o prompt abaixo e cole na conversa.
  4. Quando ele pedir para ler a pasta Downloads e gravar em ~/.claude/skills, aprove. É lá que o Claude Code procura as skills. Se o Mac perguntar se o app pode acessar a pasta Downloads, clique em Permitir.

Abra o Codex em qualquer pasta, cole o prompt abaixo e aprove quando ele pedir permissão para gravar em ~/.agents e ~/.grand-cheat-code (ficam fora da pasta aberta). No fim, feche e abra o Codex.

A versão para o Codex chega em 18/11, junto com o resto do pacote. Nesse dia, volte aqui: o prompt de instalação para o Codex aparece nesta aba. Até lá, use o Claude Code ou o aplicativo do Claude.

  1. O aplicativo não enxerga as suas pastas, então aqui o prompt não serve: as skills entram uma a uma.
  2. Descompacte o pacote (dois cliques no Mac; no Windows, botão direito e "Extrair tudo").
  3. No Claude: Configurações → Recursos, ligue Criar e editar arquivos.
  4. Personalizar → Skills → + → Criar skill → Enviar uma skill, e escolha cada .zip da pasta para-o-aplicativo/.
  5. Numa conversa nova, escreva: começar o Grand Cheat Code.

        
        
O prompt não leva senha nem link. Ele só procura no seu computador o arquivo que você baixou.
