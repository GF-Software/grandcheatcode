Perguntas

Direto ao ponto

Preciso saber programar?

Não para o guia e para o pacote de Organização. Os pacotes de construção ensinam o caminho, mas pedem que você instale o Claude Code.

Recebo tudo no dia da compra?

Não. No dia você recebe o Comece aqui e a Organização. Os outros pacotes entram na sua licença nas datas escritas nesta página.

Posso compartilhar com a minha equipe?

Não. A licença é pessoal e cada arquivo leva o número dela. Você pode usar nos projetos dos seus clientes, desde que quem opera seja você.

Que dados as skills enviam?

Qual skill rodou, a versão, a etapa e se deu certo. Nunca seus arquivos, conversas, código ou o nome do seu projeto. Dá para desligar.

Funciona com outra IA?

As skills são feitas para o Claude. O guia explica onde as outras ferramentas entram.
